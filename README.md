## Frequently Asked Questions
Here are answers to some common questions:

**Q: Is this tool compatible with Windows 7 or 8?**
A: Shutdown Timer 2026 is officially designed and tested for Windows 10 and Windows 11. While it might function on older versions, we cannot guarantee full compatibility or support for them.

**Q: Will the application continue to work if my computer enters sleep mode?**
A: Yes. The tool is built to wake the system from sleep if a timer is scheduled to run. It uses Windows Task Scheduler under the hood to ensure reliable execution.

**Q: Can I use the portable version without installing?**
A: Absolutely. After downloading, you can choose the "Portable" option during setup or simply extract the application files and run `ShutdownTimer.exe` directly.

**Q: What happens if I accidentally close the application?**
A: If you have an active timer scheduled through the GUI, it is registered with the Windows Task Scheduler. The task will execute at the scheduled time even if the main application window is closed.
